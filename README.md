# だんグラ Web MRデモ

段ボール製MRグラス「[だんグラ](https://dangla.jp/)」用の、インストール不要のWebホログラムデモです。
スマホのブラウザで開くだけで、サイドバイサイド立体視のMR（複合現実）体験ができます。

**▶ https://manahiyo831.github.io/dangla-web-mr/**

**対応環境**: 3DoFモード = iPhone / Android ／ **6DoFモード = Android Chrome（ARCore対応端末）のみ**
（iPhoneのSafariはWebXRのARに非対応のため、6DoFボタンは表示されません）

## 仕組み

だんグラは光学シースルー型（スマホ画面 → ミラー → ハーフミラーで実視野に重畳）なので、
**画面の黒い部分は透明になり、明るいピクセルだけが空中に浮かぶホログラム**として見えます。
このデモは黒背景に発光体だけを左右2眼分描画しています（three.js・単一HTML・外部通信なし）。

- **3DoFモード** — ジャイロで頭の回転に追従（iPhone / Android）
- **6DoFモード** — WebXR (ARCore) で位置もトラッキングし、ホログラムの周りを歩ける（Android Chromeのみ、マーカー不要）

## 操作方法

1. 上のURLをスマホで開く
2. 「開始（3DoF）」または「開始（6DoF）」をタップ
   - 6DoFは **画面の自動回転をONにして横向きにしてから**押す（開始時の向きで固定されるため）
3. スマホをだんグラにセット
4. **画面タップ** = シーン切替（ソーラーシステム / ホロダッシュボード / ギャラクシー）
5. **右上 ⚙** = 設定パネル / **左上 ✕** = 6DoF終了
6. 6DoF中は左下に状態表示が出ます:
   - 「6DoF: OK x= y= z=」= 位置トラッキング動作中
   - 「回転のみ」「初期化中」= 背面カメラが塞がれていないか・部屋の明るさを確認

## 調整方法（初回のみ・設定はブラウザに保存されます）

⚙ 設定パネルで以下の順に合わせてください:

1. **左右反転 / 上下反転 / 左右入替** — 像の向きが正しく見える組み合わせにする（ミラー光学の反転補正）
2. **左右レンズ間隔** — **3Dに融像するまで内側（マイナス方向）へ寄せる**。
   無調整では映像中心の間隔がだんグラのレンズ間隔より広く、3Dに見えません。最重要の調整です（調整例: -41px）
3. **瞳孔間距離** — 自分の瞳孔間距離に合わせる（調整例: 55mm）
4. **視野角** — 6DoFで頭を左右にゆっくり振り、ホログラムが**その場に静止**して見える値に。
   ついてくる→下げる / 逆に動く→上げる（既定41.9°は公式SDKの設計値）
5. **映像スケール** — 1.0 のまま（定位合わせは視野角で行います）

## 既知の限界

- 6DoFでホログラムが「動いて少し戻る」ように見えるのは、トラッキング→表示のレイテンシによるもので、公式アプリでも同様です
- 視野角と映像サイズはだんグラの光学系（ハードウェア）で決まります
